BRECKLYN NOBLE — PORTFOLIO WEBSITE

To preview:
1. Unzip this folder.
2. Open index.html in a web browser.
3. Use the navigation menu to visit the separate pages.

To customize:
- Replace the colorful photo placeholder blocks with your own images.
- Update the sample email on contact.html.
- Add dates, details, production photos, project links, and any accomplishments you want to feature.
- Edit the text directly in the HTML files using a text editor.

The site uses Google Fonts when internet access is available; it falls back to standard fonts if not.
